1. a copy of the source repository at the release commit;
2. an export/backup of the relevant Supabase question-bank data;
3. screenshots or screen recordings of the running product;
4. the release commit SHA and deployment identifier;
5. dated notes identifying the creator, contributors, and any assigned/licensed third-party assets;
6. SHA-256 hashes of archived source/export files where practical.

Keep these archives in storage controlled by the owner and do not rely only on a public Git repository as proof of ownership.
